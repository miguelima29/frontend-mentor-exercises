# Frontend Mentor - Social Links Profile

This is my solution to the Social Links Profile challenge from Frontend Mentor. The goal was to recreate the provided design using semantic HTML and CSS while implementing hover states and responsive layout techniques.

## Overview

### The challenge

Users should be able to:

- View the optimal layout depending on their device's screen size
- See hover states for all interactive elements

## My process

### Built with

- Semantic HTML5
- CSS Custom Properties (Variables)
- Flexbox
- Google Fonts (Inter)
- Mobile-first workflow

### What I learned

While building this project, I practiced:

- Structuring a card layout using Flexbox
- Organizing design tokens with CSS variables
- Working with hover states
- Importing and applying custom fonts
- Understanding the difference between buttons and links in HTML
- Improving spacing consistency using reusable variables

Example of a hover interaction used in the project:

```css
.container:hover h1 {
  color: var(--color-green);
}
```

I also learned that elements like `button` do not always inherit typography styles from their parent elements and may require explicit inheritance.

### Continued development

In future projects I want to focus on:

- Responsive design
- CSS Grid
- Accessibility best practices
- More advanced hover and animation effects
- Writing cleaner and more reusable CSS

The goal was to understand the concepts and implement the solution myself.
